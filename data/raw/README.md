# Raw Dataset Directory (`data/raw/`)

This directory is designated exclusively for raw, untouched benchmark dataset files:
- **NSL-KDD**: `KDDTrain+.txt`, `KDDTest+.txt`, `KDDTrain+_20Percent.txt`, etc.
- **CICIDS2017**: Raw CSV packet flow files generated by CICFlowMeter.

> [!WARNING]
> **Strict Requirement**: Files in `data/raw/` MUST NEVER be modified or overwritten. All cleaning, transformation, and feature engineering operations must output split processed files into `data/processed/`.
